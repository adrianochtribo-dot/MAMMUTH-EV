## What is ATLAS•EVENTA™?

ATLAS•EVENTA is the world's first **bottom-up, community-verified encyclopedia of recurring local events** — from medieval borgo festivals in Italy to harvest celebrations in rural Japan, from Patagonian folklore gatherings to Native American seasonal ceremonies.

Unlike top-down tourism databases, ATLAS•EVENTA starts from the ground:

- **One commune at a time**
- **One verified source at a time**
- **Zero invented data. Zero hallucinations.**

Every record is validated through the **T.C.F.™ (Total Coherence Framework)** — a 4-pillar protocol that guarantees territorial coherence, ontological classification, auditability and anti-noise filtering.

## T.C.F.™ Validation Protocol

Every event record must pass all 4 pillars:

| Pillar | Name | Description |
|--------|------|-------------|
| P01 | Coerenza Territoriale | GPS coordinates + comune verified |
| P02 | Anti-Rumore MORPHEUS·JLX™ | EVENT_ID + SOURCE_TYPE verified |
| P03 | Validazione Ontologica | Category within closed taxonomy |
| P04 | Auditabilità | VERSION + SOURCE_TYPE traceable |

Accepted categories:
festa_religiosa · sagra · sagra_territoriale · palio · palio_rievocazione · rito_agrario · mercato · festival_culturale · concerto · spettacolo_strada · mostra · workshop · residenza_artistica · evento_musicale
