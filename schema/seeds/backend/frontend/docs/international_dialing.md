# SUBJECT: International Dialing Standards

## Sintesi Tecnica
- **Prefisso Internazionale (Italia)**: +39 o 0039.
- **Simbolo '+'**: Standard universale per cellulari (sostituisce il codice di uscita).
- **Simbolo '00'**: Codice di uscita standard per linea fissa in Europa.
- **Regola Fissi Italia**: Lo zero del prefisso locale va sempre mantenuto (es: +39 06...).
- **Memorizzazione**: Il formato internazionale è raccomandato per la corretta sincronizzazione con applicazioni globali.
