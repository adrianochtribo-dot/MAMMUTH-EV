# Cluster Micro-territorio — Lazio

Raggruppamenti culturali sub-provinciali usati da MAMMUTH per 
aggregare eventi con identità omogenea.

## Cluster attivi (Fase 1)

| ID | Nome | Province | Carattere culturale |
|----|------|----------|---------------------|
| LAZ-01 | Castelli Romani | RM | Vino, sagre, ville tuscolane |
| LAZ-02 | Monti Lepini | LT/FR | Abbazia Valvisciolo, borghi medievali |
| LAZ-03 | Ciociaria | FR | Rievocazioni, tradizioni contadine |
| LAZ-04 | Maremma Laziale | VT | Etruschi, feste rurali |
| LAZ-05 | Sabina | RI/RM | Olio, pellegrinaggi, borghi |
| LAZ-06 | Agro Pontino | LT | Bonifica, feste patronali |
| LAZ-07 | Roma storica | RM | Rioni, feste quartiere, patronali |

## Relazione con eventi seed

Ogni seed deve includere il campo `micro_territorio` 
con l'ID cluster (es. `LAZ-02`).
